# Material: 街角情绪盲盒 项目说明汇报

> 来源：内部完整 PRD《街角情绪盲盒产品需求文档 v2.0》（评审稿，2026-07-21）。内容为产品方提供的一手权威资料，无需外部检索。标注「建议基线 · 待评审确认」的指标为经验初值，须在技术方案评审与压测中确认。

## 1. Overview
- **产品代号**：街角情绪盲盒（Street-Corner Emotion Blind Box）· 15-Min Emotion Map
- **形态**：微信小程序（LBS 轻量化情绪地理应用），非 App、非独立 H5
- **一句话定位**：给城市散步者用的微信小程序，把 15 分钟步行圈变成有温度的情绪空间，顺路收发微小而确定的温柔
- **核心差异**：去商业化、非入侵、异步无压连接（对比导航地图）
- **一期范围（MVP）**：拾取 / 释放 / 足迹 三大主链路

## 2. Background
- **用户场景**：城市人群压力大、难以专门安排疗愈；通勤/午休/下班路上需要"顺手"获得微小确定的温柔
- **设计原则（硬约束）**：非入侵性（零打卡/无排行榜/无点赞计数）、物理共鸣（须物理进入 15m 围栏解锁）、异步无压连接（仅单向"接收此温柔"，无评论/私信/好友链）
- **形态选型理由**：目标用户集中中国城市、中低频次、强依赖 LBS 与分享；小程序无需下载、分享成本极低、可调 GPS/相机/麦克风/震动，契合"轻量、反刻意"气质

## 3. Key Info
- **北极星指标**：① 近场共鸣解锁率（进入 15m 围栏后查看盲盒比例）② 无压力留存率（连续 2 周在 15min 半径内开启罗盘散步的复访率）
- **业务目标基线**：周活"无目的开启罗盘"占比 ≥40%；违规内容曝光 ≤0.1%；无压力留存率 ≥25%；单用户平均在架盲盒数 ≤3
- **核心功能模块**：M1 情绪罗盘 / M2 近场感应解锁 / M3 情绪打包发布 / M4 温柔足迹(AIGC) / M5 设计系统 / M6 隐私风控 / M7 地理安全偏移 / M8 混合定位
- **优先级**：🔴 核心(MVP) M1/M2/M3/M6/M7/M8；🟡 重要(迭代) M4/M5；⚪ 未来规划（多城市/无障碍/皮肤）

## 4. Evidence
- **用户画像**：画像A 都市通勤疗愈者(25–38岁上班族，核心用户)；画像B 社区慢行漫步者(银发/自由职业/宝妈)；画像C 夜间散步记录者(22:00后，iOS为主)
- **典型场景**：顺路拾取（下班族遇晚霞照+温柔语）、转角释放（拍猫+晚霞选暖意橙封存）、周末回顾（AIGC 水彩情绪图卷）
- **平台级能力**：M6 位置异步保护(零实时轨迹)、M6 文本+视觉风控、M7 坐标合规偏移(≤30m)、M8 混合定位(仅前台步行高精度 5s/次)
- **非功能指标**：首屏 ≤1.5s；进入围栏→卡片弹出 ≤1s；发布提交 ≤1.5s；并发在线(单城市区) ≥5000；崩溃率 ≤0.1%

## 5. Analysis
- **价值主张验证**：用"接收此温柔"无计数、无社交关系链，规避点赞焦虑与社区攀比，回归情绪本身
- **技术权衡**：LBS 围栏精度(GPS漂移)为主要技术风险，以 3s 停留确认+网络定位兜底+围栏容差应对；AIGC 成本/延迟与内容审核误杀为最大不确定项，须在 M0 完成选型与降级验证
- **合规边界**：位置为敏感个人信息，须单独授权/告知用途/可撤回(PIPL)；匿名代号不可反查；商业广告 100% 拦截；一期严守 Non-Goals（不做社交链/不做变现/不做导航）

## 6. Outlook
- **阶段策略**：一期仅小程序；若留存与内容生态健康，后续考虑独立 App 或城市公共屏联动（不在本期）
- **里程碑**：M0 技术预研(1–2周)→ M1 MVP核心(3–6周)→ M2 体验打磨(7–8周)→ M3 足迹与AIGC(9–11周)→ M4 灰度与迭代(12周+)
- **预期价值**：建立"去商业化情绪基础设施"心智；以低打扰、高隐私的姿态切入城市情绪健康赛道
