## 致命 Bug 修复：checkReleaseState 漏返回 ready
- 用户反馈：填全三条件点提交，按钮仍无动作，反而弹出空 list 的 sheet。
- 根因：`checkReleaseState()` 的返回对象缺少 `ready` 字段（只有 `hasMedia/hasMood/hasText`），而表单 submit handler 写的是 `if (!state.ready) { showReleaseTodoSheet(); return; }`，导致 `state.ready === undefined` 始终为 falsy → 不管三条件齐不齐，sheet 都会弹；条件全满足时 items 为空，所以看到"空列表 sheet"。
- 修复：在返回值里补 `ready: hasMedia && hasMood && hasText`。
- 经验：跨函数复用的纯函数返回对象必须用「完整形状」约定；任何下游需要的字段都要落在返回值里（或显式在调用点重新计算）。
- 用 node 桩测试验证 4 种组合（all met / 无媒体 / 无情绪 / 无文字）行为全部正确。
- 待用户确认后提交 push。
