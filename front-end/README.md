# 街角情绪盲盒 · 移动端 H5 前端方案

> 基于 PRD《街角情绪盲盒PRD_完整版.md》与设计系统《DESIGN.md》生成的移动端优先 H5 原型。

---

## 一、设计风格参考

### 1.1 设计稿与参考来源

本套 H5 的视觉风格综合了以下参考：

| 来源 | 说明 |
|------|------|
| **上传截图 1/2** | Wellness / Meditation 类 App 界面，特征为 pastel 薰衣草紫、桃粉、暖橙渐变，玻璃拟态卡片，超大圆角，pill 形按钮，底部浮动 Tab 栏。 |
| **Apple 设计系统** | 玻璃质感（Glassmorphism）、系统字体栈、柔和弥散阴影、 backdrop-filter 模糊、顶部 pill 标签。 |
| **Lovable** | 暖调 parchment 背景、圆润 pill 交互、低信息密度布局。 |
| **DESIGN.md** | 项目自身设计规范：四色情绪色谱、Type Scale、Spacing、Shadow System。 |

### 1.2 核心视觉特征

- **色彩**： pastel 渐变背景（薰衣草紫 `#B8A9E8`、桃粉 `#F5C8D8`、暖橙 `#F8C9B0`、天蓝 `#B8D4F0`）。
- **质感**：玻璃拟态卡片（`rgba(255,255,255,0.72)` + `backdrop-filter: blur(20px)`）。
- **圆角**：卡片 24–28px，按钮 pill（9999px），圆形图标按钮 44px。
- **阴影**：大面积、低对比、高模糊弥散阴影，无硬投影。
- **动效**：缓出曲线 `cubic-bezier(0.25, 1, 0.5, 1)`，呼吸动画 3s 周期。

## 三、页面结构与交互逻辑

### 3.1 情绪罗盘首页（index.html）

**页面结构：**

```
[状态栏占位]
[顶部] 左侧占位（保持布局平衡） | 位置 Pill “<时段>散步 · 上海”（随主题自动切换） | 设置按钮
[英雄区] WELCOME, 散步者 + “街角情绪盲盒”大标题 + 副标题
[核心]  主题联动水波纹情绪罗盘画布（3 层涟漪 + 当前位置 + 5 个可爱表情呼吸光点）
[底部]  Glass Card：附近还有 3 份温柔 + “去拾取温柔”按钮
[浮动]  FAB “+” 发布按钮
[底部]  浮动 Tab 栏：罗盘 / 足迹 / 我的
```

**交互逻辑：**
- 呼吸光点为「可爱表情球」风格：由 `app.js` 随机生成 5 个直径 22–32px 的圆球，球内嵌入 4 套不同表情 SVG（微笑 / 眯眼笑 / 星星眼 / 俏皮吐舌），随索引循环对应 4 种情绪色（紫 / 粉 / 蓝 / 暖橘）。外层使用 `color-mix` 主题色降透明度叠加阴影，制造柔光晕与高光环；顶部 `::after` 加上径向高光圆点，让球体更有立体感。统一 **1.5s 周期** 呼吸缩放（`scale(1) ↔ scale(1.12)`），与时段主题联动。
- 点击“去拾取温柔”跳转 `pickup.html`。
- 点击 FAB “+” 跳转 `release.html`。
- 底部 Tab 当前项高亮（`active` 类 + 图标上移）。
- **视角模式切换（v2.2 · 15min ↔ 50m）**：
  - 点击罗盘水波纹区域（或键盘 Enter/Space）可在「15min 全圈」与「50m 近场」两种视角模式间切换。
  - **50m 近场**：罗盘整体放大 1.06、外圈水波纹暂停并淡至 0.22、内层新增虚线近场环、中心位置点放大并增强光晕；距中心 > 18% 的远场呼吸光点以 250ms 缓动淡出。
  - **15min 全圈**：还原所有视觉参数与呼吸光点；卡片“附近还有 N 份温柔”恢复为原始数字与文案。
  - **防抖/动画锁**：切换动画时长 250ms，期内通过 `isAnimating` 标志位忽略所有点击；同时给画布添加 `is-locked` 类临时禁用 `pointer-events`，动画完成（约 280ms）后自动恢复。
  - **可访问性**：画布使用 `role="button"`、`tabindex="0"`，并通过 `aria-label` 与 `aria-live` 同步当前模式给屏幕阅读器；尊重 `prefers-reduced-motion`。
  - 模式状态文案在画布下方的 pill（`#compass-scope`）实时更新：`15min 步行圈 · 点击切换近场` ↔ `50m 近场 · 点击回到全圈`。

- **导航律动动画**（v2.1）：
  - **悬停反馈**：导航项悬停/聚焦时图标 `translateY(-3px) scale(1.12)`，文字色过渡为品牌深色，轻柔自然。
  - **序列入场**：页面加载时 Tab 项从下方 18px 处依次淡入缩放（delay 0ms / 75ms / 150ms），形成节奏感。
  - **滑动指示器**：`.tab-indicator` 位于激活项中心下方，切换或悬停预览时沿底部平滑移动（`320ms cubic-bezier(0.34,1.56,0.64,1)`），并带渐变色流动与弹性脉冲。
  - **按压缩放**：点击/按下时 `scale(0.96)`，松开复位，提供清晰触觉反馈。
  - **兼容性**：全部使用 CSS transform / opacity 动画，启用 `will-change` 与 `requestAnimationFrame`，支持 `prefers-reduced-motion` 可通过系统设置减弱动效。
- **图标优化**：首页中心「当前位置」图标与底部 Tab「罗盘」图标统一使用标准 map-pin SVG，2px 圆角描边、比例更均衡、与顶部位置 Pill 的图标风格一致；语义保持为“定位/罗盘”。
- **顶部菜单移除**：首页左上角汉堡菜单按钮已移除；左侧使用等宽占位元素保持 `justify-content: space-between` 布局平衡，未引入空白间距或错位。经检查，`app.js` 与样式表中均无菜单展开/收起的事件监听或状态管理代码需要清理。

### 3.1.5 动态时段主题系统（themes.js）

**设计目标：**
每次打开小程序时，根据当前访问时间自动切换一套与之契合的 pastel 主题，并联动水波纹、呼吸光点、背景光晕与按钮光晕，带来“每次都不一样”的惊喜感。

**时间槽与主题池：**

| 时间段 | 小时 | 预设主题 |
|--------|------|----------|
| 清晨 | 05–10 | `morning-warm`（暖橘晨光） / `morning-fresh`（薄荷晨露） |
| 午后 | 11–16 | `afternoon-sky`（晴空蓝） / `afternoon-lavender`（薰衣草午后） |
| 傍晚 | 17–20 | `evening-sunset`（落日珊瑚） / `evening-rose`（玫瑰暮光） |
| 深夜 | 21–04 | `night-lavender`（深薰衣草） / `night-midnight`（午夜蓝） |

**随机机制：**
- 启动时由 `themes.js` 的 `pickTheme()` 根据当前小时定位时间槽。
- 从该时间槽的 2 套主题中随机选择 1 套，并通过 `localStorage`（`xj_last_theme_id`）避免连续两次选中同一套，提升不可预测性。
- 选中后 `applyTheme()` 立即把品牌主色、强调色、页面背景、阴影光晕、背景光球、水波纹颜色、呼吸光点颜色等 30+ 个 CSS 变量注入 `<html>`，保证首屏无闪屏。

**水波纹联动：**
- 首页罗盘水波纹拆分为 `.compass-ripple--bg` + 3 层 `.compass-ripple--ring`。
- 每套主题配置独立的 `ripple` 参数：`speed`（扩散速度倍率）、`radiusOffset`（半径偏移百分比）、`opacityMultiplier`（透明度倍率）。
- `applyRippleTheme()` 在 DOM 就绪后计算每层的 `animation-duration`、`animation-delay`、`inset` 与 `opacity`，使波纹随主题一起变化。

**时间问候：**
- 顶部 Pill 的时段文案（如“清晨散步”）会随时间槽自动更新为 清晨 / 午后 / 傍晚 / 深夜。

**兼容性：**
- 与设置页的深色/浅色/跟随系统模式（`data-theme-mode`）互不冲突：时段主题控制配色盘，系统模式控制明暗反色。
- 所有页面均引入 `themes.js`，确保跨页主题一致。

### 3.2 拾取页（pickup.html）

**页面结构：**

```
[顶部] 返回按钮 + “你走进了一份温柔”标题
[核心]  近场脉冲动画（3 层扩散圆环 + 心形中心）
[底部 Sheet] 微光卡片：媒体区 + 情绪标签 + 微气候 + 140 字文本 + “接收此温柔”按钮
```

**媒体区实现（红框示意图替换方案）：**
- 使用可复用组件 `.media-cover.mood-media` 替换原有 SVG 占位图。
- 默认填充 `assets/image/card-img.png`（晚霞橘猫），保持 `16:10` 比例、`object-fit: cover`、20px 圆角与柔和阴影。
- 图片加载成功后添加 `.is-loaded` 类，触发淡入 + 悬停微缩放动效。
- **回退机制**：若图片加载失败，`app.js` 的 `initMediaCover()` 会切换 `.is-error` 类，隐藏 `<img>` 并显示原始渐变装饰 SVG，保留示意图作为默认显示。
- 媒体区为纯图片展示，不再叠加播放按钮，保持画面简洁。

**交互逻辑：**
- 进入页面 1.2s 后自动触发 `navigator.vibrate([60, 300, 60])` 模拟心跳震感。
- 微光卡片默认已滑出（open 状态）。
- 点击“接收此温柔”：
  - 触发粒子 burst 扩散动画（18 颗 pastel 粒子）。
  - 按钮变为“已接收这份温柔”。
  - 900ms 后卡片淡出并关闭。

### 3.3 发布页（release.html）

**页面结构：**

```
[顶部] 关闭 + “种下一个温柔盲盒”标题 + 更多
[媒体区] 媒体捕捉区（空状态 / 图片预览 / 录音状态三态切换）+ 拍照 / 录音 5s 按钮
[情绪区] 四色情绪色谱（松弛/微甜/发呆/暖意）单选
[文字区] ≤140 字文本输入 + 实时字数统计
[关联区] 微气候 chips：位置 / 天气 / 时间
[提交]  “留在此时此地”主按钮
```

**交互逻辑：**
- **媒体捕捉三态切换**：空状态 / 图片预览 / 录音状态，通过 `#media-capture` 的 `data-state` 属性切换，过渡动画 260ms。
- **拍照（仅示意图）**：点击「拍照」按钮后，仅显示预设示意图 `assets/image/uploading image.png`（长椅街景），不调用摄像头、不唤起文件选择、不保存真实照片。示意图在媒体区居中、按比例裁剪展示（`object-fit: cover`），带底部渐变遮罩与右上角移除按钮；点击移除可回到空状态。真实拍照相关的文件输入、摄像头调用、拍照预览、照片保存等模块已移除。
- **录音 5 秒**：点击「录音 5s」按钮进入录音状态：波形条动画启动、时长倒计时（`00:00 / 00:05`）、状态文案变为「正在录音…」、按钮禁用并显示「录音中」。5 秒结束后自动停止，显示中央播放按钮，状态文案变为「轻触播放回放」。
- **播放回放**：点击中央播放按钮开始模拟回放，波形条随机动、时长正计时，5 秒后自动结束；再次点击可暂停并复位。
- **移除媒体**：图片/录音预览右上角均有移除按钮，点击后回到空状态并 Toast 提示。
- 点击情绪色块切换 `selected` 状态，并同步 `input[name="mood"]`。
- 文本域实时统计字数，超出 140 自动截断。
- 提交时：
  - 校验 mood 是否已选，未选弹出 Toast。
  - 触发粒子 burst + 震动。
  - 按钮进入“正在封存…” → “已留在这个街角”。
  - 1.2s 后 Toast 提示并跳转首页。

### 3.4.5 分享系统（share.js）

**支持的渠道与降级策略：**

| 渠道 | 真实 SDK | 降级路径 |
|------|----------|----------|
| 微信好友 | `wx.updateAppMessageShareData`（需后端 JSSDK 签名） | `weixin://` 唤起微信；非微信内提示"请在微信中打开" |
| 朋友圈 | `wx.updateTimelineShareData`（需后端 JSSDK 签名） | 同上，提示"请在微信中打开后分享到朋友圈" |
| 小红书 | 假设的 `xhs.shareNote`（无公开 Web SDK） | `xhsdiscover://` 唤起 App；小红书内引导用户手动发布 |
| 复制链接 | `navigator.clipboard.writeText` | 降级到 `document.execCommand('copy')` + 隐藏 textarea |
| 生成分享卡 | Canvas 离线渲染主题色分享卡 → 触发下载 | 不可用时 Toast 提示 |

**统一分享面板 UI：**
- 标题"分享这份温柔" + 关闭按钮
- 分享卡片预览（缩略图 / 标题 / 描述 / 域名）
- 3 个主渠道图标（微信好友 / 朋友圈 / 小红书），非微信内访问时灰色禁用 + Toast 引导
- 底部"复制链接"和"生成分享卡"两个次级操作
- 280ms 滑入/滑出动画，点击遮罩或按 Esc 关闭

**分享卡生成（Canvas）：**
- 720×1280 竖版
- 自动读取当前主题 CSS 变量（`--color-background` / `--color-primary` 等）
- 包含顶部小标、标题、媒体装饰卡、底部品牌文案
- 通过 `canvas.toBlob('image/png')` 触发下载

**回调与反馈：**
- 每个渠道返回 `{ ok, pending?, channel, fallback?, error? }` Promise
- `pending` 表示已唤起但需用户在原生界面确认（如微信右上角菜单），不自动关闭
- `ok && !pending` 的成功路径会在 700ms 后自动关闭面板
- 失败且非降级（fallback）情况显示"分享失败，请稍后再试"
- 任何渠道的 Toast 反馈统一通过内置 `showToast`（未注入时降级为 `window.showToast`）

**接入其他页面：**
```html
<button data-share-trigger>分享</button>
<script src="js/share.js"></script>
<script>
  document.querySelector('[data-share-trigger]').addEventListener('click', () => {
    XJShare.open({ title: '...', desc: '...', link: location.href, image: '...', tags: [...] });
  });
</script>
```

- **编辑昵称**：点击昵称弹出 Sheet 输入框（≤20 字实时计数），保存后同步更新头部显示。
- **下拉刷新**：在页面顶部下拉超过阈值触发刷新动画，刷新后随机更新统计数字并 Toast「已是最新内容」。
- **上拉加载**：滚动到底部自动加载更多「最近活动」条目，加载满 4 页后显示「没有更多了」。
- **退出登录**：二次确认后 Toast 提示。
- 所有功能入口点击均弹出「即将上线」占位提示。

> 注：统计项中的「已购」为原型演示数据；按 PRD 的 Non-Goals，正式版不含商业变现，该模块可替换为「主题订阅 / 季节性皮肤」等合规形态。

### 3.6 设置页（settings.html）

**页面结构：**

```
[顶部] 返回按钮 | “设置”标题
[账号与隐私] 个人资料 / 隐私设置 / 账号安全（含密码、登录记录、权限管理）
[通知与互动] 温柔提醒 / 共鸣解锁 / 每周回顾
[外观与体验] 主题外观 / 触感反馈 / 环境音
[通用] 语言 / 清理缓存 / 帮助与反馈 / 关于
[应用功能配置] 默认参数 / 快捷键 / 数据导出
[底部] 恢复默认设置 / 退出登录
```

**交互逻辑：**

- 设置入口：首页右上角齿轮图标、我的页面右上角齿轮图标均跳转至此页。
- 分组卡片：每个模块使用独立圆角玻璃卡片，带图标分组标题。

- 退出登录：二次确认后 Toast 提示。

## 九、可视化编辑器（可编辑 UI 文件）

为方便后续直接编辑与修改设计稿，本方案内置一个**可视化页面编辑器**。它完整保留每个页面的布局结构、样式属性、组件层级与交互元素，并支持文本、图片、按钮等元素的独立编辑。

### 9.1 文件清单

```
front-end/
├── editor.html            # 编辑器外壳（页面切换 + 预览 + 工具条）
└── js/
    └── editor-injected.js # 注入式编辑引擎（仅 ?edit=1 时激活）
```
> 6 个页面（index / pickup / release / footprint / me / settings）已在 `</body>` 前注入
> `<script src="js/editor-injected.js"></script>`。正常打开页面（不带参数）时编辑器**完全不激活**，视觉与交互与原稿一致。

### 9.2 如何打开

编辑器通过 iframe 加载各页面并跨文档通信，建议使用本地静态服务器（避免 `file://` 协议下的跨文档访问限制）：

```bash
cd front-end
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/editor.html
```

### 9.3 编辑方式

| 元素 | 操作 |
|------|------|
| 文本（标题 / 段落 / 导航 / 徽章 / 卡片文字 / 按钮文字） | 直接点击即可修改 |
| 图片（含卡片封面、发布页示意图） | 点击图片 → 选择本地图片替换（自动转为内联 dataURL） |
| 输入框（值） | 直接输入文字 |
| 输入框（占位提示 placeholder） | 双击输入框，弹窗编辑 |
| 链接 / 按钮跳转 | 编辑模式下被拦截，避免误跳转；页面切换请用左侧列表 |

- 改动**自动保存到浏览器 localStorage**（按页面文件名隔离）。
- 编辑模式会**固定为设计系统默认主题**（薰衣草紫），确保导出结果与原稿一致、可复现。

### 9.4 工具条功能

- **退出 / 进入编辑**：在编辑与只读预览间切换。
- **导出当前页**：把当前页面序列化为独立 HTML 下载（文件名 `<页面>.edited.html`），已清理编辑痕迹，保留全部样式与交互脚本，可直接双击运行。
- **导出全部**：依次导出 6 个页面为独立 HTML 文件。
- **重置改动**：清除当前页面的本地编辑记录并恢复原稿。

### 9.5 输出特性

- 导出的 HTML **自包含**：相对路径引用 `css/design-system.css` 与 `js/*.js` 保持不变；替换的图片以 dataURL 内联，无需额外资源。
- 完整保留：布局结构、组件层级、玻璃拟态样式、圆角 / 阴影、动态主题与交互逻辑（呼吸光点、Sheet、Tab 律动、字数统计、情绪图卷生成等）。
- 编辑痕迹（contenteditable、`data-edit-id`、编辑引擎脚本引用）在导出时被自动剥离，输出文件纯净。
