# 「我的」Tab 页面内容清单（街角情绪盲盒）

> 来源：`街角情绪盲盒PRD_完整版.md` 信息构架 · 方向：**折中方案**（轻量个人页）
> 配套线框图：`me-wireframe.svg`
> 说明：本清单为 PRD 信息构架的「我的」Tab **内容定义**，不修改任何现有代码，落地实现另行确认。

---

## 0. 重要前提（PRD 冲突说明）

PRD 中**不存在「我的」Tab**。个人空间在 PRD 里称为「**温柔足迹 / Personal Sanctuary**」，入口是底部「足迹」Tab，且被明确定义为**匿名、非入侵**式设计：

- `不存昵称 / 不存头像`
- `无排行榜、无点赞计数、无打卡天数`
- `无消息通知中心、无商业化订阅入口`

但现有 `front-end/me.html` 已实现了一套**传统「我的」页**（头像 + 可编辑昵称 + 收藏/浏览/已购 统计 + 功能列表 + 最近活动），与 PRD 原则相悖。

**本次采用折中方案**：保留头像与资料入口的轻量形态，但去掉统计数字与排行榜，融合「温柔足迹」内容，并以**系统生成的「温柔代号」**替代可编辑昵称。

## 2. 个人卡片 Profile card（`.card-glass`）

| 区块 | 内容 | 规则 |
|------|------|------|
| 头像 | 系统渐变头像 `linear-gradient(135deg,#B8A9E8,#F8C9B0)` | **不可编辑 / 不可更换**，点击仅放大预览 |
| 主名称 | 温柔代号（系统生成，不可自定义） | 例：「一位路过的风打理人」 |
| 轻标签 | 一行短语 | 例：「城市散步者 · 顺路收发温柔」——**不含任何统计数字、打卡天数、排行榜** |

**❌ 移除项（对比现有 me.html）**
- 可编辑昵称输入框
- 收藏 / 浏览 / 已购 统计数字行
- 资料编辑入口

**PRD 映射**：对应 PRD「匿名、不存昵称/头像」原则——此处做了妥协，仅保留系统生成头像与代号，不开放用户自定义，符合「最低入侵」意图。

## 3. 温柔足迹预览 Personal Sanctuary preview（合并 PRD 三大块）

> 此区直接收编 PRD「温柔足迹」的核心内容，作为 Me 页的主信息流；每条子卡带「查看全部 →」跳转 `footprint.html`（完整版）。

### 3.1 情绪时间线（周视图）
- 本周收发记录摘要（卡片/信件的发出与接收）
- 分页 20/页；空周展示插画占位
- 入口：`查看全部 →` 跳转 `footprint.html`

### 3.2 AIGC 水彩生成图卷
- 周日晚自动生成的专属水彩缩略图
- 生成耗时 ≤30s，超时留白（不阻塞）
- 入口：`查看全部 →`

### 3.3 离散余音（补定义 ⚠️）
- **PRD 仅命名、未定义**。本次暂定义为：
  > 曾接收 / 留下的简短温柔印记（文字，或 ≤5s 语音片段），按时间散列展示，单条可删除。
- ⚠️ **此为 PRD 缺口，需向相关方确认最终定义**后再落地。
- 入口：`查看全部 →`

**PRD 映射**：情绪时间线 / 水彩图卷 / 离散余音 均出自 PRD「温柔足迹」三大模块；PIPL 删除权在 D2 提供入口。

## 6. 设计原则遵循（落地时需保证）

- **匿名无压**：无头像编辑、无统计/排行、无打卡数字
- **配色**：低饱和马卡龙四色——松弛 `#D8E2DC` / 微甜 `#FFE5D9` / 发呆 `#D8E1E9` / 暖意 `#FECEB6`
- **排版**：双语标题（英文上 / 中文下），居中
- **质感**：玻璃卡 `.card-glass`
- **深色模式**：走 `html.dark` token 覆盖，**不硬编码颜色**（沿用 `themes.js` + `theme-toggle.js`）
